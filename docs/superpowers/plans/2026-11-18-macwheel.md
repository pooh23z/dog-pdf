# MacWheel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build MacWheel, a 100% offline macOS menu-bar utility that pops up a translucent radial wheel when dragging files in Finder with a modifier key (`Shift`) to convert, compress, merge PDFs, transcribe video/audio (`.txt` + `.srt`), and translate documents (`→TH` / `→EN`) directly beside the source file.

**Architecture:** Split into `MacWheelCore` (pure Swift library holding file classification, non-overwriting output path resolution, offline processing engines, and async job execution) and `MacWheel` (AppKit/SwiftUI accessory `.app` providing global Finder drag monitoring, a borderless `NSDraggingDestination` radial wheel panel, progress HUD, and menu-bar popover). Because Command Line Tools on this Mac do not bundle `xctest`, automated TDD runs via a dedicated `MacWheelTestsRunner` SwiftPM executable target (`swift run MacWheelTestsRunner`) alongside `swift build`.

**Tech Stack:** Swift 6.4, SwiftPM (`platforms: [.macOS(.v15)]`), AppKit, SwiftUI, CoreImage, ImageIO, PDFKit, Vision, WebKit, Translation.framework, `ffmpeg`, ImageMagick (`magick`), `whisper.cpp` (`whisper-cli`).

**Spec:** `docs/superpowers/specs/2026-11-18-macwheel-design.md`

## Global Constraints

- Runs **100% offline** during normal operation; zero cloud APIs or silent network requests (`scripts/setup-deps.sh` is the only script allowed to download `whisper.cpp`/GGML models when explicitly run by the user).
- **Never** overwrite or delete original source files; always write outputs beside the source file and auto-deduplicate (` (2)`, ` (3)`).
- Built for **macOS 27.0 (`arm64`)** using **Swift 6.4 SwiftPM** without Xcode.app (`swift build` / `swift run` + shell `.app` packager).
- Default drag trigger modifier is **`Shift`** (configurable to `Option` or `Control`); normal Finder drags without the trigger key held must never be intercepted.
- Compression presets: **`Balanced`** (default), **`Small`**, **`High Quality`**.
- `Merge PDF` supports **`2+ Images`**, **`2+ PDFs`**, and **`Images + PDFs`**; other mixed-type drags use **strict intersection** of actions valid for all dragged files.
- `Transcribe` outputs **both** `.txt` and `.srt` beside the media file via `whisper-cli` (Metal accelerated).
- `→TH` / `→EN` translates via offline Apple `Translation.framework` and outputs `<name> TH.txt` / `<name> EN.txt` (or preserves cue indices & timestamps for `.srt`), with automatic offline Apple `Vision` OCR fallback for scanned PDFs.
- Project location: `/Users/ppooh/.gemini/antigravity/scratch/MacWheel`; packaged application bundle name: `dist/โปรเเกรมฉันเอง.app` (`CFBundleDisplayName` and `CFBundleName` set to `โปรเเกรมฉันเอง`).

## Review Focus

1. **Filename collisions, multi-dot names, and Thai Unicode paths:** Files named `รายงาน.v1.final.pdf` or repeated conversions where `name (compressed).pdf` already exists must preserve the base stem cleanly and increment to `name (compressed) (2).pdf` without overwriting (`Task 1`: `OutputPathResolverTests`).
2. **Mixed-type & incompatible multi-file drags:** Dragging `.mov` + `.docx` must resolve to an empty shared action set (triggering a clean "No shared actions" wheel state rather than crashing or dropping a file), whereas `.jpg` + `.pdf` must resolve to `[.mergePDF, .compress, .toJPG, .toPNG]` (`Task 1`: `FileClassifierTests`).
3. **Scanned (image-only) PDFs vs zero-byte/locked PDFs:** A PDF rendered purely from an image with no embedded text must invoke the offline `Vision` OCR path to extract text for `TXT`/`→TH`/`→EN`, while a corrupted or zero-byte PDF must fail gracefully with `WheelError` leaving the original intact (`Task 3`: `PDFEngineTests`).
4. **SRT subtitle cue & timestamp preservation during translation:** Translating an `.srt` file with multi-line cues and blank lines must preserve every cue number and `HH:MM:SS,mmm --> HH:MM:SS,mmm` timestamp verbatim while translating only dialogue text (`Task 6`: `TranslationEngineTests`).
5. **Drag-wheel safety on cancel or modifier release:** Center-hub drop, outside-ring release, or releasing `Shift` mid-drag must immediately dismiss the wheel and dispatch zero jobs (`Task 7`: `WheelGeometryAndTriggerTests`).
